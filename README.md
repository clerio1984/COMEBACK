# ComeBack Moçambique

## Verificação local

Instalar dependências:

npm install

Executar verificações:

npm run verify

Criar build de produção:

npm run build

Executar servidor:

npm start

## Checklist mínimo

- TypeScript sem erros
- Build Vite sem erros
- Regras Firestore sem permissões públicas de escrita
- Credenciais administrativas não ficam no frontend
- Segredos VAPID não ficam no código-fonte
